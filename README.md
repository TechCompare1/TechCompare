# TechCompare — primeira versão

Site estático responsivo para comparação de produtos de tecnologia.

## Como abrir
Abra `index.html` no navegador.

## Como publicar
Envie estes arquivos para qualquer hospedagem de site estático (por exemplo, GitHub Pages, Netlify ou Vercel).
